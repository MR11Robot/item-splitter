# Item Splitter 🪓
A lightweight Fabric mod for Minecraft 26.1.2 that lets you split item stacks into smaller amounts using configurable keybinds.

## Features
- Split item stacks with a single keypress
- Fully configurable keybinds with custom amounts
- Works in both inventory and containers (chests, barrels, etc.)
- Config saves automatically

## How to Use
1. Press **K** to open the config screen
2. Click **Set Key** and press any key
3. Enter the amount you want to split by
4. Click **Add**
5. Hover over any item stack in a container or inventory and press your key!

## Requirements
- Minecraft 26.1.2
- Fabric Loader 0.20.1+
- Fabric API 0.155.3+26.1.2
- Java 25+

## Installation
1. Download the latest `.jar` from [Releases](https://github.com/MR11Robot/item-splitter/releases)
2. Place it in your `.minecraft/mods` folder
3. Launch Minecraft with Fabric
